Install a Redux development build

Testing firmware: Development builds are unreleased and may contain incomplete features or regressions. Use the official web flasher for the latest supported release.

Loading development firmware information...

This flasher uses the latest published development build with a fixed 500 mA battery charge current. It automatically detects whether the connected OSSM M5 Remote is Core2-based or CoreS3-based.

Full install

For first-time installation, recovery, or replacing different firmware.

Erases saved devices and settings.

Use a current desktop version of Firefox, Chrome, or Edge to flash firmware. Web Serial requires HTTPS or a page served from localhost.

Update Redux

Keeps saved devices and settings.

During installation, leave Erase device unchecked.

Use a current desktop version of Firefox, Chrome, or Edge to flash firmware. Web Serial requires HTTPS or a page served from localhost.

Not sure? Choose Full install.

Remote not listed? Core2-based remotes may require a USB driver. Install the CP210x or CH9102 driver for your operating system from the official M5Stack downloads. Which driver you need depends on the Core2 hardware revision. If unsure, install both. CoreS3-based remotes should not require an additional driver.

  1. Connect the remote using a USB data cable.
  2. Choose Full install or Update using the guidance above.
  3. Select the remote from the browser's serial-device list.
  4. In the flasher dialog, choose the displayed Redux action.
  5. For an Update, leave Erase device unchecked. A Full install resets the Redux settings either way.
  6. On the confirmation screen, click Install.
  7. Wait for flashing to finish. The remote will restart automatically.
